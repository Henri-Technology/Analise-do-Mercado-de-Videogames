# 🎮 Video Game Data Analysis

Projeto de análise de dados focado no mercado de videogames, explorando a evolução da indústria entre 1977 e 2020. O objetivo é identificar padrões, tendências e insights relevantes a partir de dados históricos de vendas globais.

---

## 📊 Sobre o Projeto

Este projeto foi desenvolvido utilizando Python e um dataset obtido do Kaggle, com informações sobre vendas de videogames ao longo das últimas décadas.

A análise busca responder perguntas como:
* Quais são os jogos mais vendidos da história?
* Quais gêneros dominaram o mercado em diferentes períodos?
* Quais empresas se destacaram ao longo do tempo?
* Em que momento o mercado atingiu seu pico de vendas?
* Como o mercado evoluiu ao longo dos anos?

## 🎯 Objetivos

* Analisar a evolução do mercado de videogames.
* Identificar os principais títulos, gêneros e publishers.
* Explorar tendências de crescimento e queda nas vendas.
* Gerar insights a partir de dados históricos.
* Praticar e aplicar conceitos de análise de dados.

## 🛠️ Tecnologias Utilizadas

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
